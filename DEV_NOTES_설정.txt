### 문제 해결 기록 (2025-08-13)

#### 발견된 문제점들
1. **익명 사용자 생성 실패**
   - 원인: 필수 필드 누락 (`profile_image`, `provider`, `provider_id`)
   - 원인: `user_type: 'anonymous'` 제약 조건 위반
   - 해결: 모든 필수 필드 포함 + `user_type: 'student'` 사용

2. **스키마 불일치**
   - 원인: DEV_NOTES의 잘못된 필드명 (`full_name`, `avatar_url`)
   - 실제: `nickname`, `profile_image` 사용
   - 해결: 실제 스키마 반영하여 문서 수정

3. **수동 삭제 시 외래키 오류**
   - 원인: 익명 사용자 부재로 익명화 실패
   - 해결: 완전 삭제 또는 익명 사용자 생성 후 익명화

#### 검증된 수동 삭제 SQL
```sql
-- 1. 개인정보 완전 삭제
DELETE FROM comment_likes WHERE user_id = '{USER_ID}';
DELETE FROM notification_recipients WHERE recipient_id = '{USER_ID}';
DELETE FROM interest_schools WHERE user_id = '{USER_ID}';
DELETE FROM school_infos WHERE user_id = '{USER_ID}';

-- 2. 통계 데이터 완전 삭제 (익명화 실패 시)
DELETE FROM comments WHERE user_id = '{USER_ID}';
DELETE FROM comment_replies WHERE user_id = '{USER_ID}';
DELETE FROM meal_images WHERE uploaded_by = '{USER_ID}';

-- 3. 사용자 삭제
DELETE FROM users WHERE id = '{USER_ID}';

-- 4. Auth 삭제는 Supabase 대시보드에서 수동 처리
```

#### 3. 상세한 단계별 로깅
- 각 테이블별 삭제/익명화 결과 로그
- 성공/실패 단계 추적 가능

- OAuth 로그인 후 콜백 라우트 실행되지 않음
