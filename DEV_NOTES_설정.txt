```javascript
// 개인정보 관련 데이터 완전 삭제
```

#### 2단계: 통계 데이터 익명화
```javascript
// "탈퇴한 사용자"로 익명화 처리

- comment_replies → user_id: '00000000-0000-0000-0000-000000000000'

```

#### 3단계: 통계 무결성 보존
```javascript
// 삭제하지 않고 유지하는 데이터
```

#### 2단계: 새 브랜치 생성 및 구조 정리
```bash
# 1차 출시 완료 후 실행할 명령어들
git checkout -b v2-restructure
git checkout main
git branch -D v2-restructure  # 기존 브랜치 삭제 (있다면)
git checkout -b v2-clean-structure

# 모노레포 구조 제거

rm -rf apps/
rm -rf packages/
```

#### 3단계: 프로젝트 루트 구조 재정리
```
eat-meal-battle/
├── src/                    # apps/app/src/ → src/
├── public/                 # apps/app/public/ → public/
├── package.json           # apps/app/package.json → package.json
├── next.config.js         # apps/app/next.config.js → next.config.js
├── tailwind.config.js     # apps/app/tailwind.config.js → tailwind.config.js
```

- **next.config.js**: 모노레포 설정 제거
