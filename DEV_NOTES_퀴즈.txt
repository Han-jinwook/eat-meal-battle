## 🚀 아이폰(iOS) 별점 랜덤 소실 버그 해결 (완료)

- **문제 현상**: 아이폰 Safari에서 페이지 새로고침 시, 메뉴에 매겨둔 별점이 간헐적으로 사라졌다가 다시 나타나거나, 아예 사라지는 현상 발생.
- **핵심 원인**: '경합 조건(Race Condition)'. 컴포넌트 내 여러 useEffect 훅이 각각 별점 상태(내 별점, 평균, 참여자 수)를 비동기적으로 불러와 덮어쓰면서 발생. 특히 iOS Safari의 공격적인 메모리 관리 및 페이지 생명주기(얼음-땡) 특성 때문에 문제가 두드러짐.
- **해결 과정**:
  1. **실패한 접근**: 배틀 계산 로직 변경, 원격 로깅 추가 등 문제의 핵심을 벗어난 수정으로 오히려 다른 기능을 망가뜨리는 실수 연발.
  2. **재분석**: 사용자의 지적으로 처음부터 코드를 재분석하여, 여러 비동기 상태 업데이트가 충돌하는 '경합 조건'을 근본 원인으로 특정.
  3. **최종 해결책**: 여러 useEffect에 흩어져 있던 별점 '초기화' 로직을 단 하나의 통합 useEffect로 리팩터링. 이 통합 훅이 필요한 모든 데이터(내 별점, 통계)를 한 번에 조회하고, 모든 데이터가 준비되었을 때 상태를 '단 한 번만' 업데이트하도록 변경. 이를 통해 경합 조건을 원천적으로 차단하고 문제 해결.
- **교훈**: 복잡한 비동기 상태 초기화는 여러 곳에 흩어두지 말고, 단일 책임 원칙에 따라 한 곳에서 순서를 보장하며 처리해야 한다. 특히 모바일 환경의 특수성을 반드시 고려해야 한다.

```typescript

```

- **isMonthChampion**: DB의 `user_champion_records.month_champion` 값 (올바른 조건)

```typescript

```

## 📆 퀴즈 장원 주차별 토요일 계산 로직 개선 (2025-07-31)

### 📋 문제 상황

- 백엔드에서는 월 1일부터 월요일 시작 주차로 계산하는데, 프론트엔드 계산 로직에 오차 발생
- 프론트엔드/백엔드 간 주차 표시 불일치로 인해 장원 트로피가 잘못된 주차에 표시되는 문제

- 주차별 대표일(토요일)을 `champion_criteria` 테이블에 직접 저장하는 방식으로 변경
- 백엔드 계산 로직을 단일 진실 공급원(single source of truth)으로 사용
- 프론트엔드에서는 DB에 저장된 주차별 토요일 날짜만 가져와 표시

```javascript
// 주차별 토요일 계산 함수 추가
function calculateWeeklySaturdays(year, month) {
  // 해당 월의 1일
  const firstDayOfMonth = new Date(year, month - 1, 1);
  
  // ISO 8601 첫 주의 월요일 찾기
  const dayOfWeek = firstDayOfMonth.getDay();
  const daysToMonday = dayOfWeek === 0 ? 1 : (8 - dayOfWeek) % 7;
  
  const firstMonday = new Date(firstDayOfMonth);
  firstMonday.setDate(1 + daysToMonday);
  
  // 각 주차별 토요일 계산 (월요일+5)
  const weeklySaturdays = {};
  let saturday = new Date(firstMonday);
  saturday.setDate(firstMonday.getDate() + 5);
  
  // 최대 5주차까지 계산
  for (let week = 1; week <= 5; week++) {
    const formattedDate = `${saturday.getFullYear()}-${String(saturday.getMonth() + 1).padStart(2, '0')}-${String(saturday.getDate()).padStart(2, '0')}`;
    weeklySaturdays[`week_${week}_saturday`] = formattedDate;
    
    // 다음 주 토요일
    saturday = new Date(saturday);
    saturday.setDate(saturday.getDate() + 7);
  }
  
  return weeklySaturdays;
}

// saveChampionCriteria 함수에 토요일 데이터 저장 추가
async function saveChampionCriteria(supabase, schoolCode, year, month, weeklyMealDays, monthlyTotal, weeklySaturdays) {

    // 기존 필드들
    school_code: schoolCode,
    year,
    month,
    week_1_days: weeklyMealDays[1] || 0,
    // ...
    
    // 주차별 토요일 필드 추가
    week_1_saturday: weeklySaturdays?.week_1_saturday || null,
    week_2_saturday: weeklySaturdays?.week_2_saturday || null,
    week_3_saturday: weeklySaturdays?.week_3_saturday || null,
    week_4_saturday: weeklySaturdays?.week_4_saturday || null,
    week_5_saturday: weeklySaturdays?.week_5_saturday || null,
  });
  // ...
}
```

### 🛠️ 새로운 플로우 구현

#### 1. 퀴즈 첫 제출 → quiz_champions 생성 + user_champion_records 기본 레코드 생성
**파일**: `apps/app/netlify/functions/quiz.js` - `submitQuizAnswer()` 함수
**위치**: quiz_champions 새 레코드 생성 성공 후 (399-445줄)

```javascript
// 🆕 퀴즈 첫 제출 시 user_champion_records 기본 레코드 생성
try {
  console.log('[quiz] user_champion_records 기본 레코드 생성 시작:', { userId, calendarMonth, calendarYear });
  
  // 사용자 학교 정보 조회
  const { data: userSchool, error: userSchoolError } = await supabaseAdmin
    .from('school_infos')
    .select('school_code, grade')
    .eq('user_id', userId)
    .single();
  
  if (userSchoolError || !userSchool) {
    console.log('[quiz] 사용자 학교 정보 조회 실패, user_champion_records 생성 건너뜀:', userSchoolError);
  } else {
    // user_champion_records 기본 레코드 생성
    const championRecordData = {
      user_id: userId,
      school_code: userSchool.school_code,
      grade: userSchool.grade,
      year: calendarYear,
      month: calendarMonth,
      week_1_champion: false,
      week_2_champion: false,
      week_3_champion: false,
      week_4_champion: false,
      week_5_champion: false,
      month_champion: false,
      created_at: new Date().toISOString()
    };
    
    const { data: championResult, error: championError } = await supabaseAdmin
      .from('user_champion_records')
      .insert([championRecordData])
      .select();
    
    if (championError) {
      console.log('[quiz] user_champion_records 생성 실패 (무시하고 계속):', championError);
    } else {
      console.log('[quiz] user_champion_records 기본 레코드 생성 성공:', championResult);
    }
  }
} catch (championRecordError) {
  console.log('[quiz] user_champion_records 생성 중 예외 (무시하고 계속):', championRecordError);
}
```

## 🏆 school_champions 테이블 집계 로직 개선 (2025-08-21)

### 📋 문제 상황
- 기존 SQL 집계에서 반별 데이터가 누락되어 UI에서 반별 통계가 0으로 표시
- `school_infos` 테이블의 `class_number` 필드를 활용하지 못함

### 🛠️ 해결 방안

#### 1. 완전 집계 SQL 작성
**반별 집계 포함한 완전한 school_champions 데이터 생성:**
```sql
-- 기존 데이터 삭제
DELETE FROM school_champions;

-- 반별 집계 포함 완전 집계
INSERT INTO school_champions (
  school_code, grade, year, month, week_number, grade_total,
  class_1, class_2, class_3, class_4, class_5, class_6, class_7, class_8, class_9, class_10,
  class_11, class_12, class_13, class_14, class_15
)
SELECT 
  ucr.school_code, ucr.grade, ucr.year, ucr.month,
  week_num as week_number, COUNT(*) as grade_total,
  COUNT(CASE WHEN si.class_number = 1 THEN 1 END) as class_1,
  COUNT(CASE WHEN si.class_number = 2 THEN 1 END) as class_2,
  -- ... (class_3 ~ class_15 동일 패턴)
FROM user_champion_records ucr
JOIN school_infos si ON ucr.user_id = si.user_id
CROSS JOIN (VALUES (1), (2), (3), (4), (5)) AS weeks(week_num)
WHERE (주차별 장원 조건)
GROUP BY ucr.school_code, ucr.grade, ucr.year, ucr.month, week_num
UNION ALL
-- 월별 집계 (동일한 패턴으로 month_champion = true 조건)
```

#### 2. championCalculator.js 자동 집계 함수 개선

**QuizClient.tsx 정리:**

```typescript
const handleUniversalSchoolChange = async (direction: 'prev' | 'next') => {
  console.log('🏫 학교 변경 요청:', { direction, currentSchool: universalSchoolName, schoolType: universalSchoolType });
  
  try {
    const { data: schoolInfos, error } = await supabase
      .from('school_infos')
      .select('school_name, school_code')
      .ilike('school_name', `%${universalSchoolType}%`)
      .order('school_name');
      
    if (error || !schoolInfos || schoolInfos.length === 0) {
      console.error('학교 목록 조회 실패:', error);
      return;
    }
    
    const currentIndex = schoolInfos.findIndex(school => 
      school.school_name === universalSchoolName
    );
    
    let nextIndex;
    if (direction === 'next') {
      nextIndex = currentIndex >= schoolInfos.length - 1 ? 0 : currentIndex + 1;
    } else {
      nextIndex = currentIndex <= 0 ? schoolInfos.length - 1 : currentIndex - 1;
    }
    
    const nextSchool = schoolInfos[nextIndex];
    
    // 상태 업데이트
    setUniversalSchoolName(nextSchool.school_name);
    setUniversalSchoolCode(nextSchool.school_code);
    
  } catch (err) {
    console.error('학교 변경 중 오류:', err);
  }
};
```
