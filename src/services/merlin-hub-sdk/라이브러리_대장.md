## 🔄 허브 인프라 변경 및 공지 (Hub Changelog)

- **2026-06-01**: **SDK v1.4.6 배포 / 임베디드 3컬럼 가로폭 800px 규격화**. 썬드림 등 공유 카드가 본문에 임베디드되는 3컬럼 레이아웃의 경우에도 본페이지 전체 가로폭은 헤더와 동일하게 무조건 800px로 제한(max-w-[800px])하고 grid-cols-[1fr_1fr_160px]을 적용하도록 명시하여 헤더 좌우 정렬을 일치시킴.
- **2026-06-01**: **SDK v1.4.5 배포 / HubShareSquare v1.0.1 패치**. 공유카드(`HubShareSquare`) 자체 가로폭을 **`160px`** (`w-[160px]`)로 하드코딩하여 고정 렌더링되도록 수정. 어떠한 레이아웃이나 그리드에 배치하더라도 160px 크기로 유지되어 디자인이 기형적으로 찢어지는 UI 결함 해결.
- **2026-06-01**: **SDK v1.4.4 배포 / 웰컴 보상 가불 과금 동기화 및 레이아웃 표준화**. 신규 가입 유저가 첫 분석 시 가불 차감액과 웰컴 보상을 원자적으로 일괄 정산하여 DB 제약조건(`balance >= 0`) 위반 에러를 완벽히 해결. 설정 페이지의 컨테이너 최대 가로폭 규격(`max-w-4xl`, 896px) 및 2컬럼 그리드 레이아웃 명세를 `라이브러리_활용가이드.md`에 공식 추가.
- **2026-05-31**: **SDK v1.4.3 배포 / 인증 모듈 v2.0.2 업데이트**. `useHubAuth.ts`에서 에러 수신 시 `result.message` 외에도 `result.error`를 폴백 체크하도록 개선하여 상세한 연동 에러 사유를 UI로 파악할 수 있도록 보완. 서버 사이드 JWT 실제 DB 유저 존재 유무 검사 추가와 연동.
- **2026-05-31**: **SDK v1.4.2 배포 / 가입 순서 추적 및 500C 보상 결함 수정**. `family_users` 테이블 내 `registered_apps` 배열 컬럼 도입을 통해 2, 3차 패밀리 앱 가입 순서 및 통계 구조 고도화. 기존 로그인 시점에 보상이 잠기던 `reward_stage = 1` 강제 세팅을 `0`(대기)으로 수정하여 최초 코인 차감 시점에 500C 보상 및 추천인 적립금이 확실하게 발급되도록 패치.
- **2026-05-25**: **SDK v1.4.1 (Hotfix) 배포 / 추천인 및 축하 코인 혜택 로직 보완**. 공유 링크 진입 시 추천인 코드(ref)를 놓치지 않도록 `ReferralTracker` 로직 추가 및 `wallet.service.ts`의 `checkAndRewardFirstActivation` 분리로 비회원 가불 정산 시점에도 가입 축하 코인 및 추천인 보상이 완벽하게 작동하도록 패치.
- **2026-05-25**: **SDK v1.4.0 배포 / HubBenefitModal v1.0.0**. 무료 체험 유저 대상 혜택 안내 모달(`HubBenefitModal`) 및 지연 노출 트리거(`useBenefitTrigger`, `markFreeTrialCompleted`) 추가. 앱별 맞춤 혜택 설정 지원. 허브 서버에 `Vaulter`(금고지기) 메일 브랜딩 분기 지원 추가.
- **2026-05-24**: **SDK v1.3.8 배포 / HubProfileCards 도입**. 프로필 설정 기능을 기존 모달에서 카드형 UI 3종(`HubProfileCard`, `HubNotificationCard`, `HubLogoutCard`)으로 전면 개편. 개별 앱 내 프로필 설정 페이지 페이지 임베딩 방식 지원.
- **2026-05-24**: **SDK v1.3.7 배포 / HubProfileModal v1.0.0**. 모든 패밀리 앱에서 공통으로 호출할 수 있는 통합 프로필 설정 모달 팝업 추가. 닉네임 수정 및 아바타 이미지 업로드, 통합 로그아웃 기능 내장.
- **2026-05-23**: **SDK v1.3.6 배포 / HubAuthModal v2.0.1**. HubAuthModal 폰트 크기 최적화(15px)로 긴 텍스트 잘림 현상 방지 및 이메일 입력 시 히스토리 내 동일 이메일 버튼 숨김(필터링) 처리하여 중복 UX 제거. 라이브러리 가이드에 SPA 프록시 브릿지 구성 강제 규정 및 Netlify `_redirects` 동적 생성 충돌 관련 트러블슈팅 안내 대폭 보강.
- **2026-05-23**: **SDK v1.3.5 배포 / HubPurchaseWidget v1.3.0**. 불필요한 잔액 박스를 제거하여 위젯 공간을 최적화하고, 서버 부하 감소를 위해 이용내역의 필터링(유형/앱/기간) 및 페이징 로직을 모두 프론트엔드(SDK) 단에서 자체 전담하도록 구조를 개편. 네이버페이 스타일의 직관적인 필터 UI 추가.
- **2026-05-23**: **동적 과금 한도 규격화 적용**. `family_apps` 내 과금 정책(`client_secret`)에 `min_price`(최저 요금 제한) 및 `max_price`(최대 요금 제한) 값을 파싱하여 요금을 클램핑하는 로직이 서버에 반영되었습니다. 어그로필터는 최대 100C(최저 10C)로 제한 한도를 규격 적용 완료.
