# 🤖 왓잇(WhatEat) 담당 AI에게 전달하는 허브(Hub) 연동 인수인계서

반갑습니다. 저는 허브(MerlinFamilyOS) 코어 시스템을 전담하는 AI '안티그래비티'입니다.
대표님의 지시에 따라 왓잇 프로젝트에 허브 연동을 위한 **'최신 SDK 기초 뼈대(Starter Kit)'** 주입을 완료하고 바통을 넘깁니다.

## 📌 제가(허브 AI) 세팅 완료한 내역
1. **최신 SDK 복사 완료**: `src/services/merlin-hub-sdk/` 폴더 내부에 허브의 통신 모듈과 표준 UI 컴포넌트(로그인 모달 등), 그리고 가이드 문서가 모두 최신화되어 배치되었습니다.
2. **Provider 래핑 확인**: 왓잇의 `src/app/layout.tsx` 최상단에 이미 `<HubProvider>`가 잘 감싸져 있는 것을 확인 및 검증했습니다.
3. **비코인 앱 설정**: 왓잇은 코인이 없는 광고 기반 앱임을 허브 쪽에 세팅 완료했습니다.

---

## 🛠️ 이제 당신(왓잇 담당 AI)이 수행해야 할 마무리 작업 (Action Items)

왓잇의 고유 기능이나 UI 레이아웃이 붕괴될 위험이 있어, 뷰(View) 단위의 시각적 배치는 왓잇을 가장 잘 아는 당신에게 양도합니다. **동봉된 `라이브러리_활용가이드.md`**를 참고하여 아래 항목을 왓잇의 고유 코드에 바인딩해 주십시오.

1. **로그인/가입 UI 바인딩**: 
   - 왓잇의 기존 헤더나 마이페이지의 '로그인' 버튼 이벤트에 허브의 인증 모달(`window.dispatchEvent(new CustomEvent('openLoginModal'))`)을 띄우도록 바인딩해 주세요.
2. **비코인 앱 예외 처리 (매우 중요)**:
   - 왓잇은 코인 과금이 없으므로, 허브 가이드 문서 중 `chargeDynamic` 관련 코인 결제 로직은 무시하셔도 됩니다.
3. **헤더 및 사용자 프로필 위젯 배치**:
   - `HubProfileWidget`이나 `HubAvatar` 같은 허브 표준 컴포넌트를 왓잇의 헤더 디자인(Margin, Padding)에 맞게 렌더링해 주세요. (레이아웃이 깨지지 않도록 유의)
4. **절대 원칙**: 
   - 이 폴더(`merlin-hub-sdk`) 안의 소스코드는 허브의 표준 라이브러리이므로 **절대 직접 수정하지 마십시오.** 
   - 버그 발견 시 왓잇 쪽에서 임의로 고치지 말고 대표님을 통해 저(안티그래비티)에게 원본 수정을 요청해야 합니다.

작업을 안전하게 마무리하고 대표님께 보고해 주십시오. 감사합니다!
