# 💾 뭐먹지? (WhatEat) 데이터베이스 스키마 명세서

본 문서는 '뭐먹지?(WhatEat)' 서비스에 활성화되어 있는 핵심 테이블과 칼럼 구조를 일목요연하게 정리한 데이터베이스 스키마 상세 명세서입니다.

---

## 📊 테이블별 칼럼 명세

### 1. `users` (회원 정보 테이블)
서비스 가입자들의 기본 개인정보 및 계정 연동 정보를 관리합니다.
| 칼럼명 | 데이터 타입 | Null 허용 여부 | 설명 |
| :--- | :--- | :--- | :--- |
| **id** | uuid | NO | 회원 고유 식별값 (기본 키) |
| **nickname** | character varying | NO | 회원 닉네임 |
| **email** | character varying | NO | 계정 이메일 주소 |
| **profile_image** | text | NO | 프로필 이미지 URL 경로 |
| **birth_date** | date | YES | 생년월일 |
| **provider** | character varying | NO | 소셜 로그인 제공자 (예: local, google, kakao) |
| **provider_id** | character varying | NO | 소셜 로그인 고유 ID |
| **created_at** | timestamp with time zone | YES | 가입 일시 |
| **is_student** | boolean | NO | 학생 여부 플래그 |
| **updated_at** | timestamp with time zone | YES | 최종 정보 변경 일시 |
| **referral_code** | character varying | YES | 회원 고유 추천인 코드 |
| **is_activated** | boolean | YES | 계정 활성화 여부 |
| **accumulated_seconds**| integer | YES | 앱 누적 이용 시간(초) |
| **region** | text | YES | 거주 지역 정보 (시도, 시군구, 읍면동이 JSON 직렬화된 문자열) |

### 2. `school_infos` (회원 매핑 학교 정보)
회원이 등록한 본인의 소속 학교, 학년, 반 정보를 매핑합니다.
| 칼럼명 | 데이터 타입 | Null 허용 여부 | 설명 |
| :--- | :--- | :--- | :--- |
| **user_id** | uuid | NO | 회원 고유 ID (외래 키, 기본 키) |
| **school_code** | text | YES | 학교 고유 코드 |
| **school_name** | text | YES | 학교 이름 |
| **school_type** | text | YES | 학교 유형 (초등, 중등, 고등) |
| **region** | text | YES | 행정구역 지역명 |
| **address** | text | YES | 학교 주소 |
| **grade** | integer | YES | 학년 |
| **class_number** | integer | YES | 반 |
| **created_at** | timestamp with time zone | YES | 생성 일시 |
| **updated_at** | timestamp with time zone | YES | 최종 수정 일시 |
| **office_code** | character varying | YES | 교육청 고유 코드 |

| 칼럼명 | 데이터 타입 | Null 허용 여부 | 설명 |

| **id** | uuid | NO | 급식 메뉴 고유 ID (기본 키) |
| **school_code** | text | NO | 대상 학교 코드 |
| **meal_date** | text | NO | 급식 해당 일자 (형식: YYYYMMDD 등) |
| **meal_type** | text | NO | 급식 구분 (조식, 중식, 석식) |
| **menu_items** | jsonb | YES | 개별 음식 반찬 정보 JSON 데이터 |
| **kcal** | text | YES | 총 칼로리량 정보 |
| **origin_info** | text | YES | 원산지 정보 텍스트 |
| **ntr_info** | text | YES | 영양 성분 정보 텍스트 |
| **created_at** | timestamp with time zone | YES | 시스템 저장 일시 |
| **updated_at** | timestamp with time zone | YES | 최종 갱신 일시 |
| **is_empty_result**| boolean | YES | 급식 정보 미제공일 여부 플래그 |
| **office_code** | character varying | YES | 소속 교육청 코드 |
| **is_temporary** | boolean | YES | 임시 저장된 식단 여부 |
