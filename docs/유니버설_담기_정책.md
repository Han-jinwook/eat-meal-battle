# 📌 유니버설 '담기' 정책 및 상태 전환 도표

본 문서는 솔로, 가족, 모임 간 식사 카드(위시리스트 및 확정 예약)를 자유롭게 넘나들며 복사/저장하는 **유니버설 담기** 기능의 허용 및 비활성화 정책을 명시한 도표입니다.
각 AI 에이전트는 이 규칙을 기준으로 `UniversalSaveModal` 및 관련 담기 로직을 유지보수해야 합니다.

---

## 💡 타겟별 담기 허용 규칙 표

| 출발 카드의 현재 위치 (Source) | 💡 솔로 위시로 담기 | 🏠 가족 위시로 담기 | 👥 모임 위시로 담기 | 📝 먹로그로 담기 |
| :--- | :--- | :--- | :--- | :--- |
| **① 솔로 > 먹로그** (먹었던 식사) | **O** (가능) | **O** (가능) | **O** (가능) | **X** (불가 - 현장사진 전용) |
| **② 솔로 > 위시리스트** (혼밥 위시) | **X** (이미 위치함) | **O** (가능) | **O** (가능) | **X** (불가 - 현장사진 전용) |
| **③ 솔로 > 확정 예약** (혼밥 날짜예약) | **X** (예약건은 솔로위시 불가) | **O** (가능) | **O** (가능) | **X** (불가 - 현장사진 전용) |
| **④ 패밀리 > 가족 위시** (가족 위시) | **O** (가능) | **X** (이미 위치함) | **O** (가능) | **X** (불가 - 현장사진 전용) |
| **⑤ 패밀리 > 확정 예약** (가족 날짜예약) | **O** (가능) | **X** (이미 위치함) | **O** (가능) | **X** (불가 - 현장사진 전용) |
| **⑥ 모임 > 모임 위시** (모임 위시) | **O** (가능) | **O** (가능) | **O** (다른 모임방) | **X** (불가 - 현장사진 전용) |
| **⑦ 모임 > 확정 예약** (모임 날짜예약) | **O** (가능) | **O** (가능) | **O** (다른 모임방) | **X** (불가 - 현장사진 전용) |

## 🛠️ 규칙 구현의 핵심 로직 요약
1. **먹로그(Meal Log)로의 담기 원천 차단**
   - 먹로그는 철저히 **현장 직찍 사진**만을 아카이빙하는 공간이므로, 담기(Wish/Schedule) 기능에서 타겟으로 제공되지 않습니다.
2. **동일 소속 영역 비활성화 방어**
   - 출발 카드가 '솔로' 생태계(위시 또는 예약)인 경우 👉 솔로 위시로의 담기는 차단됨.
   - 출발 카드가 '가족' 생태계(위시 또는 예약)인 경우 👉 가족 위시로의 담기는 차단됨.
3. **교차 영역 자유 허용**
   - 가족 확정 예약 식사라도 개인 혼밥을 위해 솔로 위시로 담을 수 있습니다. (`⑤번 로직`)
   - 솔로 확정 예약 식사라도 가족과 함께 먹기 위해 가족 위시로 추천 담기가 가능합니다. (`③번 로직`)
4. **모임방 예외 처리**
   - 모임의 경우, 출발 모임방과 도착 모임방이 서로 **다른 모임방**일 경우에 한해 담기가 허용됩니다. (동일 모임방은 중복 필터링)
