# 💾 왓잇(WhatEat) 미사용 레거시 스키마 백업 문서

본 문서는 기존 '급식배틀' 서비스에서 현재의 '뭐먹지?(WhatEat)' 서비스로 대폭 개편되면서 소스 코드 내에서 더 이상 호출·참조되지 않게 된 미사용 테이블 17개의 DDL 스키마를 보존하고, 데이터베이스에서 일괄 삭제할 수 있도록 정리한 기록보관 문서입니다.

---

## 1. 🗑️ 삭제 대상 테이블 DDL 상세 정의

### 1) 퀴즈 및 챔피언 시스템 관련 테이블 (9개)

#### ① `all_quiz_attempts` (퀴즈 풀기 시도 이력)
```sql
CREATE TABLE public.all_quiz_attempts (
    id uuid DEFAULT extensions.uuid_generate_v4() NOT NULL,
    user_id uuid,
    quiz_id uuid,
    selected_option integer,
    is_correct boolean,
    answer_time integer,
    attempted_at timestamp without time zone DEFAULT now(),
    school_code text,
    grade integer
);
```

## 2. 🪓 일괄 테이블 삭제(DROP TABLE) SQL 스크립트

아래 SQL 스크립트를 실행하면 위 18개 미사용 테이블을 데이터베이스에서 완전히 삭제합니다. 
(외래키 제약조건이 걸려있는 관계를 안전하게 끊고 삭제하기 위해 `CASCADE` 옵션을 부여합니다.)

```sql
DROP TABLE IF EXISTS public.all_quiz_attempts CASCADE;
DROP TABLE IF EXISTS public.all_quiz_daily_stats CASCADE;
DROP TABLE IF EXISTS public.champion_criteria CASCADE;
DROP TABLE IF EXISTS public.quiz_champions CASCADE;
DROP TABLE IF EXISTS public.quiz_reports CASCADE;
DROP TABLE IF EXISTS public.quiz_results CASCADE;
DROP TABLE IF EXISTS public.quiz_viewers CASCADE;
DROP TABLE IF EXISTS public.school_champions CASCADE;
DROP TABLE IF EXISTS public.user_champion_records CASCADE;

DROP TABLE IF EXISTS public.meal_battle_daily CASCADE;
DROP TABLE IF EXISTS public.meal_battle_monthly CASCADE;
DROP TABLE IF EXISTS public.menu_battle_daily CASCADE;
DROP TABLE IF EXISTS public.menu_battle_monthly CASCADE;
DROP TABLE IF EXISTS public.menu_item_ratings CASCADE;
DROP TABLE IF EXISTS public.menu_item_rating_stats CASCADE;

DROP TABLE IF EXISTS public.rating_settings CASCADE;
DROP TABLE IF EXISTS public.notification_recipients CASCADE;
DROP TABLE IF EXISTS public.notifications CASCADE;
```
