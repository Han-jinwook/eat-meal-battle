## 🏫 관심학교 컴포넌트 개발 중요사항 (2025-08-06)

### 🎯 핵심 문제
**새로고침 시 관심학교 드롭다운 버튼이 사라지는 현상**
- 원인: React 조건부 렌더링으로 인한 컴포넌트 언마운트
- 발생 시점: 페이지 새로고침, 다른 페이지 갔다 오기
- 영향: 사용자 경험 저하, 기능 접근성 문제

### 🔍 기술적 분석

#### 현재 급식 페이지 구조 (page.tsx)
```typescript
// Line 387-401: 기존 학교 헤더
{userSchool ? (
  <div className="bg-gradient-to-r from-blue-50 to-indigo-50...">
    <span>{userSchool.school_name}</span>
    // 학년/반 정보
  </div>
) : (
  <div className="mb-6"></div>
)}
```

**문제점:**
- `userSchool` 상태에 의존하는 조건부 렌더링
- 새로고침 시 `userSchool` 로딩 지연으로 컴포넌트 사라짐
- `useUserSchool` 훅의 비동기 로딩 특성

### 🎯 해결 전략

#### 1. 조건부 렌더링 최소화
```typescript
// ❌ 잘못된 접근
{userSchool && <InterestSchoolDropdown />}

// ✅ 올바른 접근
<div className="header-container">
  {userSchool ? <SchoolInfo /> : <LoadingState />}
  <InterestSchoolDropdown /> {/* 항상 표시 */}
</div>
```

#### 2. 컴포넌트 설계 원칙
- **독립성**: 관심학교 컴포넌트는 userSchool과 독립적으로 작동
- **안정성**: 로딩/에러 상태와 관계없이 항상 마운트
- **분리**: 기존 학교 헤더 코드 절대 수정 금지

#### 3. 상태 관리 방식
```typescript
// 관심학교 선택 상태는 localStorage 활용
const STORAGE_KEY = 'interest_school_selected';

// 새로고침 시 상태 복원
useEffect(() => {
  const savedSchool = localStorage.getItem(STORAGE_KEY);
  if (savedSchool) {
    setSelectedSchool(JSON.parse(savedSchool));
  }
}, []);
```

### 🗄️ 데이터베이스 설계

#### interest_schools 테이블
```sql
CREATE TABLE interest_schools (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  school_name TEXT NOT NULL,
  school_code TEXT NOT NULL,
  office_code TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

#### 필수 테스트 시나리오
1. **새로고침 테스트**: F5 후 버튼 유지 확인
2. **페이지 이동 테스트**: 배틀→퀴즈→급식 이동 후 상태 확인
3. **로딩 상태 테스트**: 네트워크 지연 시 버튼 표시 확인
4. **에러 상태 테스트**: userSchool 로딩 실패 시 버튼 유지 확인
